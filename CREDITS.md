# CREDITS

На текущем этапе игра использует встроенные пиксельные fallback-ассеты, которые генерируются в коде для игрока, NPC, станций, тайлов пола и предметов мини-игр.

Начиная с недели 4, клиент поддерживает drop-in PNG ассеты через папку `src/LosPollosHermanos.App/Assets/`.

## Внешние открытые ассеты

- Kenney Topdown Shooter Pack
  - Автор: Kenney Vleugels (Kenney.nl)
  - Лицензия: Creative Commons Zero, CC0
  - Ссылка: https://kenney.nl/assets/top-down-shooter
  - Источник лицензии в репозитории: `kenney_top-down-shooter.zip/License.txt`
  - Использование: проект поддерживает подключение PNG-ассетов из папки `Assets`; текущая сборка сохраняет кодовые fallback-спрайты, чтобы игра запускалась без обязательной распаковки внешних файлов.

Когда в проект будут добавлены внешние пиксель-арт ассеты, здесь нужно зафиксировать:

- источник;
- автора;
- лицензию;
- список измененных файлов/спрайтов.
